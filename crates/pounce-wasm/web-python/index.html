POUNCE + Pyomo in the browser

Write a Pyomo model in Python, solve it with POUNCE — both running in this tab. Pyodide supplies CPython and Pyomo compiled to WebAssembly; Pyomo writes the AMPL .nl, the POUNCE wasm module solves it, and the .sol is loaded back so x.value and model.dual[c] read as they would after any local solve. No server, no install, nothing uploaded.

Script

pounce_browser.solve(model, options=…) takes ipopt.opt-format options — the same names the POUNCE CLI and Python API use. Ctrl/⌘-Enter runs.
